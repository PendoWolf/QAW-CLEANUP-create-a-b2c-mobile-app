# Clearlist Mobile

The React Native Android version of the Clearlist todo app, built with Expo.

## Run on Android

1. Install [Android Studio](https://developer.android.com/studio) and start an emulator, or install Expo Go on an Android device.
2. Install dependencies with `npm install`.
3. Run `npm run android`.

To use a physical device, run `npm start` and scan the QR code with Expo Go.

Tasks are saved locally on the device with AsyncStorage.
